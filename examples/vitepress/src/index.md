VitePress is a Vite-based rewrite from the same team behind VuePress. Same target (Vue-flavored docs sites), different backend: VitePress trades VuePress's webpack-era complexity for Vite's instant dev server and faster production builds. The contract wiring is a few lines in `.vitepress/config.mjs`.
